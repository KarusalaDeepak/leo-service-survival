# Focused review audit

These compact tables support the final manuscript review revision:

- raw-versus-final-calibrated scheduler comparisons and block-level inference;
- EOS input-screening and selection-consequence counts;
- WetLinks regular-grid gap summaries and endpoint descriptives; and
- configuration and source-hash manifests.

The repository intentionally excludes the row-level prediction, EOS candidate,
EOS task, and WetLinks source tables used to construct these aggregates. Their
licenses and access conditions remain with the original sources. The public
builder is `scripts/build_manuscript_audits.py`.

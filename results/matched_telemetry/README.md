# Aggregate OneWeb telemetry descriptors

These files contain bounded derived summaries, not raw address-bearing measurement logs. The LENS OneWeb source is Jinwei Zhao and Jianping Pan, LENS (OneWeb) 2024, DOI 10.5281/zenodo.15786332, with dataset description at https://github.com/clarkzjw/LENS/tree/master/oneweb. The source describes its dataset terms as CC BY-SA 4.0: https://creativecommons.org/licenses/by-sa/4.0/.

Modifications include selecting a short Iowa interval, aligning observed assignment transitions and accepted RTT records, and exporting before/after summary statistics. These data-derived summaries retain CC BY-SA 4.0 attribution/share-alike terms; that notice does not relicense original author software. They do not establish an installed routing action, physical cause, or causal task benefit.
